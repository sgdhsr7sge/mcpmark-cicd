# mcpmark-cicd

A lightweight Node.js Express application with comprehensive testing and CI/CD practices.

## Features

- Express.js REST API
- Comprehensive test suite with Jest
- Code quality tools (ESLint, Prettier)
- CI/CD workflows

## Getting Started

### Installation

```bash
npm install
```

### Running the Application

```bash
npm start
```

### Development

```bash
npm run dev
```

### Testing

```bash
npm test
npm run test:coverage
```

### Linting

```bash
npm run lint
npm run lint:fix
```

### Formatting

```bash
npm run format
```

## API Endpoints

- `GET /` - Welcome message
- `GET /health` - Health check
- `GET /api/status` - API status
